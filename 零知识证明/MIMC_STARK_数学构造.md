# MIMC STARK 的数学构造

> 基于 [Vitalik STARKs Part 3](https://vitalik.eth.link/general/2018/07/21/starks_part_3.html) 的数学重述

---

## 1. 计算问题的定义

### 1.1 MIMC 函数

给定输入 $s_0$，轮常数序列 $\{k_0, k_1, ..., k_{n-1}\}$，MIMC 定义为：

$$s_{i+1} = s_i^3 + k_{i \mod m} \pmod{p}$$

其中 $p$ 是素数模数，$m$ 是轮常数的周期。

### 1.2 计算轨迹

执行 $n$ 步后得到**计算轨迹**：

$$\text{Trace} = (s_0, s_1, s_2, ..., s_{n-1})$$

**目标**：证明从 $s_0 = input$ 出发，经过 $n$ 步计算，得到 $s_{n-1} = output$。

---

## 2. 多项式编码

### 2.1 定义域

设 $g$ 是 $n$ 阶单位根，即 $g^n = 1$，且 $g^i \neq 1$ 对于 $0 < i < n$。

定义**轨迹域**：

$$H = \{1, g, g^2, ..., g^{n-1}\}$$

### 2.2 轨迹多项式 $P(x)$

通过拉格朗日插值，构造唯一的度数 $< n$ 的多项式 $P(x)$，使得：

$$P(g^i) = s_i \quad \text{对于 } i = 0, 1, ..., n-1$$

即：

| $x$ | $1$ | $g$ | $g^2$ | ... | $g^{n-1}$ |
|-----|-----|-----|-------|-----|-----------|
| $P(x)$ | $s_0$ | $s_1$ | $s_2$ | ... | $s_{n-1}$ |

### 2.3 轮常数多项式 $K(x)$

类似地，构造多项式 $K(x)$，使得：

$$K(g^i) = k_{i \mod m}$$

由于轮常数周期为 $m$，$K(x)$ 的度数为 $m-1$。

---

## 3. 约束的代数化

### 3.1 转换约束 (Transition Constraint)

对于每一步 $i \in \{0, 1, ..., n-2\}$，必须满足：

$$s_{i+1} = s_i^3 + k_i$$

用多项式表达：

$$P(g \cdot x) = P(x)^3 + K(x) \quad \text{对于 } x \in \{1, g, g^2, ..., g^{n-2}\}$$

定义**约束多项式**：

$$C(x) = P(g \cdot x) - P(x)^3 - K(x)$$

则 $C(x) = 0$ 在 $x \in \{1, g, ..., g^{n-2}\}$ 上成立。

### 3.2 零化多项式 $Z(x)$

$C(x)$ 在 $n-1$ 个点上为零，因此 $C(x)$ 可被**零化多项式**整除：

$$Z(x) = \prod_{i=0}^{n-2}(x - g^i) = \frac{x^n - 1}{x - g^{n-1}}$$

### 3.3 商多项式 $D(x)$

如果计算正确，则存在多项式 $D(x)$ 使得：

$$C(x) = Z(x) \cdot D(x)$$

即：

$$\boxed{P(g \cdot x) - P(x)^3 - K(x) = Z(x) \cdot D(x)}$$

**度数分析**：
- $\deg(P) < n$
- $\deg(P^3) < 3n$
- $\deg(C) < 3n$
- $\deg(Z) = n-1$
- $\deg(D) < 2n+1$

---

## 4. 边界约束 (Boundary Constraints)

### 4.1 约束条件

需要证明：
- $P(1) = input$
- $P(g^{n-1}) = output$

### 4.2 插值多项式 $I(x)$

构造过两点 $(1, input)$ 和 $(g^{n-1}, output)$ 的直线：

$$I(x) = \frac{(x - g^{n-1}) \cdot input + (1 - x) \cdot output}{1 - g^{n-1}}$$

### 4.3 边界零化多项式 $Z_2(x)$

$$Z_2(x) = (x - 1)(x - g^{n-1})$$

### 4.4 边界商多项式 $B(x)$

如果边界条件成立，则 $P(x) - I(x)$ 在 $x = 1$ 和 $x = g^{n-1}$ 处为零，因此：

$$P(x) - I(x) = Z_2(x) \cdot B(x)$$

即：

$$\boxed{B(x) = \frac{P(x) - I(x)}{(x-1)(x-g^{n-1})}}$$

**度数**：$\deg(B) < n - 2$

---

## 5. 低度扩展 (Low-Degree Extension)

### 5.1 扩展域

设 $g_2$ 是 $n \cdot \rho$ 阶单位根（$\rho$ 是扩展因子，通常 $\rho = 8$），满足 $g_2^\rho = g$。

定义**扩展域**：

$$L = \{1, g_2, g_2^2, ..., g_2^{n \cdot \rho - 1}\}$$

### 5.2 关系图

```
┌─────────────────────────────────────────────────────────────────────┐
│                      单位根的圆周排列                                │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│                           ·  g_2                                    │
│                       ·         ·                                   │
│                   ·                 ·  g_2²                         │
│               ·                         ·                           │
│           g_2^(n·ρ-1)                      ·                        │
│               ·                         ·                           │
│                   ·                 ·                               │
│                       ·         ·                                   │
│                           · 1                                       │
│                                                                     │
│  黑点: g 的幂次 (轨迹域 H)                                          │
│  紫点: g_2 的幂次 (扩展域 L)                                        │
│  轨迹域 H ⊂ 扩展域 L                                                │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

### 5.3 多项式求值

在扩展域 $L$ 上计算：
- $P(x)$ 在所有 $x \in L$ 上的值
- $D(x)$ 在所有 $x \in L$ 上的值
- $B(x)$ 在所有 $x \in L$ 上的值

### 5.4 Merkle 承诺

将三元组 $(P(x), D(x), B(x))$ 对于每个 $x \in L$ 组织成 Merkle 树，根记为 $\text{Root}$。

---

## 6. 证明结构

### 6.1 证明者提供

**1. Merkle 根**：$\text{Root}_{P,D,B}$

**2. 随机线性组合**：

设 $k_1, k_2, k_3, k_4$ 由 $\text{Root}$ 哈希派生，构造：

$$L(x) = D(x) + k_1 \cdot P(x) + k_2 \cdot P(x) \cdot x^n + k_3 \cdot B(x) + k_4 \cdot B(x) \cdot x^n$$

**目的**：将三个多项式的低度证明合并为一个。

**度数**：$\deg(L) < 2n$

**3. FRI 低度证明**：证明 $L(x)$ 的度数 $< 2n$

**4. 随机抽查点**：对于 $t$ 个随机位置 $x_i \in L \setminus H$，提供：
- $P(x_i), D(x_i), B(x_i)$ 的值
- $P(g \cdot x_i)$ 的值
- 对应的 Merkle 分支

---

## 7. 验证过程

对于每个抽查位置 $x$，验证者检查：

### 7.1 转换约束检查

$$P(g \cdot x) - P(x)^3 - K(x) \stackrel{?}{=} Z(x) \cdot D(x)$$

其中 $Z(x) = \frac{x^n - 1}{x - g^{n-1}}$ 可由验证者直接计算。

### 7.2 边界约束检查

$$P(x) \stackrel{?}{=} B(x) \cdot (x-1)(x-g^{n-1}) + I(x)$$

### 7.3 线性组合检查

$$L(x) \stackrel{?}{=} D(x) + k_1 P(x) + k_2 P(x) x^n + k_3 B(x) + k_4 B(x) x^n$$

### 7.4 Merkle 路径验证

验证所有值确实在承诺的 Merkle 树中。

### 7.5 FRI 低度验证

验证 $L(x)$ 确实是度数 $< 2n$ 的多项式。

---

## 8. 安全性分析

### 8.1 完备性 (Completeness)

如果证明者诚实执行了 MIMC 计算，则所有验证检查都会通过。

### 8.2 可靠性 (Soundness)

设 $|L| = n \cdot \rho$，$t$ 为抽查次数。

如果计算轨迹有错误，则：
- $C(x) \neq Z(x) \cdot D(x)$ 作为多项式
- 两边最多在 $\deg(C) \approx 3n$ 个点上"碰巧"相等
- 随机抽一个点，发现错误的概率 $\geq 1 - \frac{3n}{n \cdot \rho} = 1 - \frac{3}{\rho}$

抽 $t$ 次后，作弊成功的概率：

$$\epsilon \leq \left(\frac{3}{\rho}\right)^t$$

当 $\rho = 8, t = 40$ 时，$\epsilon \leq 2^{-80}$。

---

## 9. 核心数学等式总结

```
┌─────────────────────────────────────────────────────────────────────┐
│                    STARK 的核心数学等式                              │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  【轨迹编码】                                                       │
│  P(gⁱ) = sᵢ  (计算轨迹的第 i 步)                                   │
│                                                                     │
│  【转换约束】                                                       │
│  P(g·x) - P(x)³ - K(x) = Z(x)·D(x)                                 │
│                                                                     │
│  【边界约束】                                                       │
│  P(x) - I(x) = Z₂(x)·B(x)                                          │
│                                                                     │
│  【零化多项式】                                                     │
│  Z(x) = (xⁿ - 1)/(x - gⁿ⁻¹)                                        │
│  Z₂(x) = (x - 1)(x - gⁿ⁻¹)                                         │
│                                                                     │
│  【低度组合】                                                       │
│  L(x) = D(x) + k₁P(x) + k₂P(x)xⁿ + k₃B(x) + k₄B(x)xⁿ              │
│  deg(L) < 2n                                                        │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```
