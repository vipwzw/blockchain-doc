## 1. 基础概念

### 1.1 什么是低度多项式

多项式的**度数**是指多项式中最高次项的幂次：

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           多项式度数的定义                                   │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  多项式: P(X) = a₀ + a₁X + a₂X² + ... + aₙXⁿ                              │
│                                                                             │
│  度数 (degree): deg(P) = n（最高非零项的幂次）                             │
│                                                                             │
│  示例:                                                                      │
│  ───────                                                                    │
│  • P(X) = 3X² + 2X + 1        → 度数 = 2                                   │
│  • P(X) = X⁷ + 5X³ - 2       → 度数 = 7                                   │
│  • P(X) = 42 (常数)           → 度数 = 0                                   │
│                                                                             │
│  低度多项式 vs 高度多项式（相对概念）:                                     │
│  ─────────────────────────────────────                                      │
│  设定度数阈值 d:                                                           │
│  • 低度多项式: deg(P) < d                                                  │
│  • 高度多项式: deg(P) ≥ d                                                  │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 1.2 多项式的来源与要求

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                    证明者的多项式从哪里来？                                  │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  在完整的零知识证明系统中，多项式不是随意选择的！                          │
│                                                                             │
│  【多项式的来源】                                                           │
│  ────────────────                                                           │
│                                                                             │
│  1. 计算问题 → 算术电路 → 多项式约束                                       │
│                                                                             │
│     例如: 证明 "我知道 x 使得 x³ + x + 5 = 35"                             │
│           ↓                                                                 │
│     转化为多项式约束: 存在多项式 P(X) 满足特定条件                         │
│                                                                             │
│  2. 执行轨迹编码                                                           │
│                                                                             │
│     • 将计算的每一步状态编码为多项式的系数或求值                           │
│     • 约束条件编码为多项式之间的关系                                       │
│                                                                             │
│  【多项式的要求】                                                           │
│  ────────────────                                                           │
│                                                                             │
│  1. 度数限制: deg(P) < d                                                   │
│     • d 由问题规模决定（通常是计算步数的函数）                             │
│     • FRI 用来证明这个度数限制被满足                                       │
│                                                                             │
│  2. 满足约束: P 必须满足由原问题导出的约束方程                             │
│     • 这些约束由 STARK/AIR 等协议定义                                      │
│     • FRI 只负责证明度数，约束检查由其他部分负责                           │
│                                                                             │
│  3. 定义域: 多项式系数在有限域 F_q 中                                      │
│     • 所有运算都是模 q 的                                                  │
│     • q 通常是大素数或素数幂                                               │
│                                                                             │
│  【本示例中】                                                               │
│  ────────────                                                               │
│  为了演示 FRI 协议，我们直接给定一个满足度数要求的多项式                   │
│  P(X) = 3 + 2X + 5X² + X³                                                  │
│                                                                             │
│  实际系统中，这个多项式是由前端编译器从计算问题自动生成的                   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 2. 问题定义

### 2.1 FRI 要解决的问题

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                        FRI 解决的核心问题                                    │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  输入:                                                                      │
│  ──────                                                                     │
│  • 证明者提交向量 V = [v₀, v₁, v₂, ..., vₙ₋₁]                             │
│  • 证明者声称: 存在度数 < d 的多项式 P(X)，使得 vᵢ = P(ωⁱ)               │
│    其中 ω 是 n 次单位根 (ωⁿ = 1)                                          │
│                                                                             │
│  问题:                                                                      │
│  ──────                                                                     │
│  验证者如何高效验证这个声称？                                              │
│                                                                             │
│  约束:                                                                      │
│  ──────                                                                     │
│  • 验证者不能检查所有 n 个值（n 可能很大）                                 │
│  • 需要在 O(log n) 复杂度内完成验证                                        │
│  • 需要是非交互式的（一次性证明）                                          │
│                                                                             │
│  关键参数:                                                                  │
│  ──────────                                                                 │
│  • n: 求值点数量（必须是 2 的幂）                                          │
│  • d: 度数上限（多项式度数 < d）                                           │
│  • ρ = d/n: 码率（通常 ρ ≤ 1/2，即 n ≥ 2d）                               │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 2.2 为什么 n 必须是 2 的幂？

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                    n 必须是 2 的幂的原因                                     │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  FRI 的折叠操作需要将向量长度反复减半:                                     │
│                                                                             │
│  n → n/2 → n/4 → n/8 → ... → 1                                            │
│                                                                             │
│  如果 n 不是 2 的幂，某一步就无法精确减半                                  │
│                                                                             │
│  例如:                                                                      │
│  ────────                                                                   │
│  n = 8 = 2³  ✓                                                             │
│  8 → 4 → 2 → 1  (共 3 轮折叠)                                             │
│                                                                             │
│  n = 6  ✗                                                                  │
│  6 → 3 → ???  (3 是奇数，无法继续减半)                                    │
│                                                                             │
│  实际系统中的处理:                                                         │
│  ──────────────────                                                         │
│  如果原始数据长度不是 2 的幂，会进行填充 (padding)                         │
│  将长度扩展到最近的 2 的幂                                                 │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 2.3 索引配对问题：为什么不会溢出？

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                    索引配对与"溢出"问题                                      │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  在折叠时，我们将位置 i 和位置 i + n/2 配对:                               │
│                                                                             │
│  V⁽⁰⁾ = [v₀, v₁, v₂, v₃, v₄, v₅, v₆, v₇]   (n = 8)                        │
│                                                                             │
│  配对方式:                                                                  │
│  • (v₀, v₄)  →  位置 0 和 0+4                                             │
│  • (v₁, v₅)  →  位置 1 和 1+4                                             │
│  • (v₂, v₆)  →  位置 2 和 2+4                                             │
│  • (v₃, v₇)  →  位置 3 和 3+4                                             │
│                                                                             │
│  【不存在溢出问题】                                                         │
│  ─────────────────                                                          │
│                                                                             │
│  折叠时，i 只从 0 到 n/2 - 1:                                              │
│  • i ∈ {0, 1, 2, ..., n/2 - 1}                                            │
│  • i + n/2 ∈ {n/2, n/2 + 1, ..., n - 1}                                   │
│                                                                             │
│  最大索引: (n/2 - 1) + n/2 = n - 1 ✓ 刚好在范围内                         │
│                                                                             │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │                                                                     │   │
│  │   位置:  0   1   2   3   4   5   6   7                             │   │
│  │         [v₀][v₁][v₂][v₃][v₄][v₅][v₆][v₇]                           │   │
│  │          │   │   │   │   │   │   │   │                             │   │
│  │          └───┼───┼───┼───┘   │   │   │                             │   │
│  │              └───┼───┼───────┘   │   │                             │   │
│  │                  └───┼───────────┘   │                             │   │
│  │                      └───────────────┘                             │   │
│  │                                                                     │   │
│  │   前半部分 [0, n/2)     后半部分 [n/2, n)                          │   │
│  │   每个前半位置与后半对应位置配对                                    │   │
│  │                                                                     │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│  【为什么这样配对？】                                                       │
│  ──────────────────                                                         │
│                                                                             │
│  因为 ω^(n/2) = -1（n 次单位根的性质）                                     │
│                                                                             │
│  所以: ω^(i+n/2) = ω^i · ω^(n/2) = ω^i · (-1) = -ω^i                      │
│                                                                             │
│  即位置 i 和 i+n/2 对应的求值点是 ω^i 和 -ω^i，互为相反数！               │
│  这正是奇偶分解所需要的配对方式                                            │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 3. 折叠公式推导

### 3.1 多项式的奇偶分解

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                       多项式奇偶分解                                         │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  任何多项式都可以分解为偶次项和奇次项:                                     │
│                                                                             │
│  P(X) = a₀ + a₁X + a₂X² + a₃X³ + a₄X⁴ + a₅X⁵ + ...                       │
│                                                                             │
│       = (a₀ + a₂X² + a₄X⁴ + ...) + (a₁X + a₃X³ + a₅X⁵ + ...)             │
│         ─────────────────────────   ─────────────────────────              │
│                偶次项                        奇次项                         │
│                                                                             │
│       = (a₀ + a₂X² + a₄X⁴ + ...) + X·(a₁ + a₃X² + a₅X⁴ + ...)            │
│                                                                             │
│  定义:                                                                      │
│  ──────                                                                     │
│  Pₑᵥₑₙ(Y) = a₀ + a₂Y + a₄Y² + ...    (偶次项，变量换成 Y)                 │
│  Pₒdd(Y)  = a₁ + a₃Y + a₅Y² + ...    (奇次项系数，变量是 Y)               │
│                                                                             │
│  则:                                                                        │
│  ────                                                                       │
│  P(X) = Pₑᵥₑₙ(X²) + X · Pₒdd(X²)                                          │
│                                                                             │
│  【具体例子】                                                               │
│  ────────────                                                               │
│  P(X) = 3 + 2X + 5X² + X³                                                  │
│                                                                             │
│  偶次项: 3 + 5X²  →  Pₑᵥₑₙ(Y) = 3 + 5Y                                    │
│  奇次项: 2X + X³ = X(2 + X²)  →  Pₒdd(Y) = 2 + Y                          │
│                                                                             │
│  验证:                                                                      │
│  P(X) = Pₑᵥₑₙ(X²) + X·Pₒdd(X²)                                            │
│       = (3 + 5X²) + X·(2 + X²)                                             │
│       = 3 + 5X² + 2X + X³                                                  │
│       = 3 + 2X + 5X² + X³ ✓                                                │
│                                                                             │
│  【度数性质】                                                               │
│  ────────────                                                               │
│  如果 deg(P) = d，则:                                                      │
│  • deg(Pₑᵥₑₙ) ≤ ⌊d/2⌋                                                    │
│  • deg(Pₒdd) ≤ ⌊(d-1)/2⌋                                                  │
│                                                                             │
│  度数减半！这是 FRI 能递归的关键                                           │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 3.2 利用 P(X) 和 P(-X) 提取奇偶部分

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                    从 P(X) 和 P(-X) 提取 Pₑᵥₑₙ 和 Pₒdd                      │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  由 P(X) = Pₑᵥₑₙ(X²) + X · Pₒdd(X²)                                       │
│                                                                             │
│  代入 -X:                                                                   │
│  P(-X) = Pₑᵥₑₙ((-X)²) + (-X) · Pₒdd((-X)²)                                │
│        = Pₑᵥₑₙ(X²) - X · Pₒdd(X²)                                         │
│                                                                             │
│  现在有两个方程:                                                           │
│  ───────────────                                                            │
│  P(X)  = Pₑᵥₑₙ(X²) + X · Pₒdd(X²)    ... (1)                              │
│  P(-X) = Pₑᵥₑₙ(X²) - X · Pₒdd(X²)    ... (2)                              │
│                                                                             │
│  解这个方程组:                                                             │
│  ──────────────                                                             │
│                                                                             │
│  (1) + (2):  P(X) + P(-X) = 2·Pₑᵥₑₙ(X²)                                   │
│                                                                             │
│              Pₑᵥₑₙ(X²) = [P(X) + P(-X)] / 2                               │
│                                                                             │
│  (1) - (2):  P(X) - P(-X) = 2X·Pₒdd(X²)                                   │
│                                                                             │
│              Pₒdd(X²) = [P(X) - P(-X)] / (2X)                              │
│                                                                             │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │                                                                     │   │
│  │   关键公式:                                                         │   │
│  │                                                                     │   │
│  │   Pₑᵥₑₙ(X²) = [P(X) + P(-X)] / 2                                   │   │
│  │                                                                     │   │
│  │   Pₒdd(X²)  = [P(X) - P(-X)] / (2X)                                │   │
│  │                                                                     │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 3.3 折叠操作的推导

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                       FRI 折叠操作推导                                       │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  【目标】                                                                   │
│  ────────                                                                   │
│  给定随机挑战 α，定义折叠后的多项式:                                       │
│                                                                             │
│      P'(Y) = Pₑᵥₑₙ(Y) + α · Pₒdd(Y)                                       │
│                                                                             │
│  我们需要从 P(X) 的求值 [P(ω⁰), P(ω¹), ..., P(ωⁿ⁻¹)]                      │
│  计算出 P'(Y) 的求值 [P'(ω⁰), P'(ω²), ..., P'(ω^(n-2))]                   │
│                                                                             │
│  注意: P'(Y) 在 Y = ω^(2i) 处求值 (即 X² 对应的点)                        │
│                                                                             │
│  【推导】                                                                   │
│  ────────                                                                   │
│                                                                             │
│  在点 X = ωⁱ 处:                                                           │
│  • P(ωⁱ) 已知 (这是 v⁽⁰⁾ᵢ)                                                │
│                                                                             │
│  在点 X = -ωⁱ = ω^(i+n/2) 处:                                              │
│  • P(-ωⁱ) = P(ω^(i+n/2)) 也已知 (这是 v⁽⁰⁾ᵢ₊ₙ/₂)                         │
│                                                                             │
│  根据前面的公式:                                                           │
│  Pₑᵥₑₙ((ωⁱ)²) = [P(ωⁱ) + P(-ωⁱ)] / 2                                     │
│               = [v⁽⁰⁾ᵢ + v⁽⁰⁾ᵢ₊ₙ/₂] / 2                                   │
│                                                                             │
│  Pₒdd((ωⁱ)²) = [P(ωⁱ) - P(-ωⁱ)] / (2·ωⁱ)                                 │
│              = [v⁽⁰⁾ᵢ - v⁽⁰⁾ᵢ₊ₙ/₂] / (2·ωⁱ)                               │
│                                                                             │
│  所以折叠后在点 Y = (ωⁱ)² = ω^(2i) 处的值:                                │
│                                                                             │
│  P'(ω^(2i)) = Pₑᵥₑₙ(ω^(2i)) + α · Pₒdd(ω^(2i))                            │
│                                                                             │
│             = [v⁽⁰⁾ᵢ + v⁽⁰⁾ᵢ₊ₙ/₂]/2 + α·[v⁽⁰⁾ᵢ - v⁽⁰⁾ᵢ₊ₙ/₂]/(2·ωⁱ)       │
│                                                                             │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │                                                                     │   │
│  │   FRI 折叠公式:                                                     │   │
│  │                                                                     │   │
│  │   v⁽¹⁾ᵢ = (v⁽⁰⁾ᵢ + v⁽⁰⁾ᵢ₊ₙ/₂)/2 + α·(v⁽⁰⁾ᵢ - v⁽⁰⁾ᵢ₊ₙ/₂)/(2·ωⁱ)    │   │
│  │                                                                     │   │
│  │   其中 i ∈ {0, 1, ..., n/2 - 1}                                    │   │
│  │                                                                     │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│  【等价形式】                                                               │
│  ────────────                                                               │
│  设 a = v⁽⁰⁾ᵢ, b = v⁽⁰⁾ᵢ₊ₙ/₂, 则:                                        │
│                                                                             │
│  v⁽¹⁾ᵢ = (a + b)/2 + α·(a - b)/(2·ωⁱ)                                     │
│                                                                             │
│       = [(a + b)·ωⁱ + α·(a - b)] / (2·ωⁱ)                                 │
│                                                                             │
│       = [a·(ωⁱ + α) + b·(ωⁱ - α)] / (2·ωⁱ)                                │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 3.4 为什么折叠保持低度性质？

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                    折叠保持低度性质的证明                                    │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  【定理】如果 deg(P) < d，则 deg(P') < d/2                                 │
│                                                                             │
│  【证明】                                                                   │
│  ────────                                                                   │
│                                                                             │
│  设 P(X) = Σᵢ aᵢXⁱ，度数 < d                                              │
│                                                                             │
│  则:                                                                        │
│  • Pₑᵥₑₙ(Y) = a₀ + a₂Y + a₄Y² + ... 的度数 < d/2                          │
│  • Pₒdd(Y) = a₁ + a₃Y + a₅Y² + ... 的度数 < d/2                           │
│                                                                             │
│  因此:                                                                      │
│  P'(Y) = Pₑᵥₑₙ(Y) + α·Pₒdd(Y)                                             │
│                                                                             │
│  两个度数 < d/2 的多项式的线性组合，度数仍然 < d/2 ✓                       │
│                                                                             │
│  【递归】                                                                   │
│  ────────                                                                   │
│                                                                             │
│  • 第 0 轮: P⁽⁰⁾ 度数 < d,     求值点数 n                                 │
│  • 第 1 轮: P⁽¹⁾ 度数 < d/2,   求值点数 n/2                               │
│  • 第 2 轮: P⁽²⁾ 度数 < d/4,   求值点数 n/4                               │
│  • ...                                                                      │
│  • 第 k 轮: P⁽ᵏ⁾ 度数 < d/2ᵏ,  求值点数 n/2ᵏ                              │
│  • 最终: 常数多项式 (度数 = 0)                                             │
│                                                                             │
│  总轮数: log₂(d)                                                           │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 5. 非交互式证明构造

### 5.1 Fiat-Shamir 变换

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                       Fiat-Shamir 变换                                       │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  【核心思想】                                                               │
│  ────────────                                                               │
│  将交互式协议中验证者的"随机挑战"替换为对之前所有消息的哈希                │
│                                                                             │
│  交互式:                                                                    │
│    证明者 → 消息₁ → 验证者                                                │
│    证明者 ← 随机挑战₁ ← 验证者（真随机）                                   │
│    证明者 → 消息₂ → 验证者                                                │
│    证明者 ← 随机挑战₂ ← 验证者（真随机）                                   │
│    ...                                                                      │
│                                                                             │
│  非交互式 (Fiat-Shamir):                                                   │
│    证明者计算 消息₁                                                        │
│    α₁ = Hash(消息₁)                  ← 哈希代替随机                        │
│    证明者计算 消息₂                                                        │
│    α₂ = Hash(消息₁ || 消息₂)        ← 包含所有历史                        │
│    ...                                                                      │
│    证明者一次性发送所有消息                                                │
│                                                                             │
│  【安全性】                                                                 │
│  ──────────                                                                 │
│  • 在随机预言机模型下可证明安全                                            │
│  • 哈希输出被假定为"看起来随机"                                            │
│  • 证明者无法预测哈希输出，因此无法作弊                                    │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 5.3 生成随机挑战并折叠

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                    第一轮：生成 α₁ 并折叠                                    │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  【生成随机挑战 α₁】                                                       │
│  ──────────────────                                                         │
│                                                                             │
│  α₁ = Hash("FRI" || root₀) mod 17                                          │
│     = Hash("FRI" || 233) mod 17                                            │
│     = 3  (假设哈希结果)                                                    │
│                                                                             │
│  【计算折叠】                                                               │
│  ────────────                                                               │
│                                                                             │
│  折叠公式: v⁽¹⁾ᵢ = (vᵢ + vᵢ₊₄)/2 + α₁·(vᵢ - vᵢ₊₄)/(2·ωⁱ)  (mod 17)       │
│                                                                             │
│  其中 2⁻¹ = 9 (mod 17)                                                     │
│                                                                             │
│  位置 i=0: (ω⁰ = 1, 1⁻¹ = 1)                                              │
│  ────────────────────────────                                               │
│  v₀ = 11, v₄ = 7                                                           │
│  v⁽¹⁾₀ = (11 + 7)·9 + 3·(11 - 7)·9·1  (mod 17)                            │
│       = 18·9 + 3·4·9                                                       │
│       = 162 + 108 = 270                                                    │
│       = 270 mod 17 = 15                                                    │
│                                                                             │
│  位置 i=1: (ω¹ = 2, 2⁻¹ = 9)                                              │
│  ────────────────────────────                                               │
│  v₁ = 1, v₅ = 9                                                            │
│  v⁽¹⁾₁ = (1 + 9)·9 + 3·(1 - 9)·9·9  (mod 17)                              │
│       = 10·9 + 3·(-8)·81                                                   │
│       = 90 - 1944                                                          │
│       = -1854 mod 17 = 16                                                  │
│                                                                             │
│  位置 i=2: (ω² = 4, 4⁻¹ = 13)                                             │
│  ────────────────────────────                                               │
│  v₂ = 5, v₆ = 9                                                            │
│  v⁽¹⁾₂ = (5 + 9)·9 + 3·(5 - 9)·9·13  (mod 17)                             │
│       = 14·9 + 3·(-4)·117                                                  │
│       = 126 - 1404 = -1278 mod 17 = 10                                    │
│                                                                             │
│  位置 i=3: (ω³ = 8, 8⁻¹ = 15)                                             │
│  ────────────────────────────                                               │
│  v₃ = 1, v₇ = 15                                                           │
│  v⁽¹⁾₃ = (1 + 15)·9 + 3·(1 - 15)·9·15  (mod 17)                           │
│       = 16·9 + 3·(-14)·135                                                 │
│       = 144 - 5670 = -5526 mod 17 = 3                                     │
│                                                                             │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │   V⁽¹⁾ = [15, 16, 10, 3]                                           │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│  【构建 V⁽¹⁾ 的 Merkle 树】                                                │
│  ──────────────────────────                                                 │
│                                                                             │
│  N₀₁ = H(15, 16) = 15 + 2×16 = 47                                         │
│  N₂₃ = H(10, 3)  = 10 + 2×3  = 16                                         │
│  root₁ = H(47, 16) = 47 + 2×16 = 79                                       │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                    第二轮：生成 α₂ 并折叠                                    │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  【生成随机挑战 α₂】                                                       │

│  ────────────                                                               │
│                                                                             │

### 5.4 查询数量 λ 的确定

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                    查询数量 λ 的确定                                         │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  【λ 是什么？】                                                             │
│  ─────────────                                                              │
│  λ 是独立查询的次数，每次查询检查一个随机位置的折叠关系                    │
│  多次查询可以指数级降低作弊者逃脱检测的概率                                │
│                                                                             │
│  【单次查询的检测概率】                                                     │
│  ──────────────────────                                                     │
│  如果证明者作弊（V⁽⁰⁾不是低度多项式的求值），                              │
│  单次随机查询有 ≥ p 的概率检测到错误                                       │
│                                                                             │
│  p ≥ (1 - ρ) / 2                                                           │
│                                                                             │
│  其中 ρ = d/n 是码率                                                       │
│                                                                             │
│  【λ 次查询后的安全性】                                                     │
│  ────────────────────                                                       │
│  作弊逃脱概率 ≤ (1 - p)^λ                                                  │
│                                                                             │
│  在本例中 ρ = 4/8 = 0.5，所以 p ≥ 0.25                                    │
│  作弊逃脱概率 ≤ 0.75^λ                                                     │
│                                                                             │
│  【如何选择 λ？】                                                           │
│  ────────────────                                                           │
│  目标：作弊逃脱概率 ≤ 2^(-κ)，其中 κ 是安全参数（通常 128 bit）           │
│                                                                             │
│  计算：                                                                     │
│  (1 - p)^λ ≤ 2^(-κ)                                                        │
│  λ ≥ κ / log₂(1/(1-p))                                                     │
│  λ ≥ κ / log₂(1/0.75)                                                      │
│  λ ≥ κ / 0.415                                                              │
│  λ ≥ 2.41 × κ                                                               │
│                                                                             │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │                                                                     │   │
│  │   常见 λ 值选择:                                                    │   │
│  │                                                                     │   │
│  │   ρ = 1/2 (本例):                                                  │   │
│  │   • κ = 80 bit 安全:  λ ≈ 193                                      │   │
│  │   • κ = 128 bit 安全: λ ≈ 309                                      │   │
│  │                                                                     │   │
│  │   ρ = 1/4 (更好的码率):                                            │   │
│  │   • p ≥ 0.375                                                       │   │
│  │   • κ = 128 bit 安全: λ ≈ 190                                      │   │
│  │                                                                     │   │
│  │   ρ = 1/8:                                                          │   │
│  │   • p ≥ 0.4375                                                      │   │
│  │   • κ = 128 bit 安全: λ ≈ 153                                      │   │
│  │                                                                     │   │
│  │   实际系统中通常选择 λ ∈ [30, 200] 根据安全需求                    │   │
│  │                                                                     │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│  【本例中的简化】                                                           │
│  ────────────────                                                           │
│  为了演示，我们只展示 λ = 1（单次查询）                                    │
│  实际系统需要多次独立查询                                                  │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 5.5 生成查询位置

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                    生成查询位置（非交互式）                                  │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  【生成初始查询位置】                                                       │
│  ────────────────────                                                       │
│                                                                             │
│  查询位置通过哈希生成，保证非交互式:                                       │
│                                                                             │
│  query_seed = Hash("FRI_QUERY" || root₀ || root₁ || root₂ || c)           │
│             = Hash("FRI_QUERY" || 233 || 79 || 24 || 8)                    │
│                                                                             │
│  初始查询位置 i₀ = query_seed mod (n/2) = query_seed mod 4                │
│                                                                             │
│  注意：查询范围是 [0, n/2) 而不是 [0, n)                                   │
│        因为位置 i 和 i + n/2 是配对的，只需从前半部分选一个                │
│                                                                             │
│  假设 query_seed mod 4 = 2，所以初始查询位置 i₀ = 2                        │
│                                                                             │
│  【多个查询位置的生成（当 λ > 1 时）】                                     │
│  ─────────────────────────────────────                                      │
│                                                                             │
│  如果需要 λ 个独立查询:                                                    │
│                                                                             │
│  for j = 0 to λ-1:                                                         │
│      seed_j = Hash("FRI_QUERY" || root₀ || root₁ || root₂ || c || j)      │
│      i₀^(j) = seed_j mod (n/2)                                             │
│                                                                             │
│  例如 λ = 3:                                                               │
│  • seed_0 = Hash(...||0), i₀^(0) = seed_0 mod 4 = 2                        │
│  • seed_1 = Hash(...||1), i₀^(1) = seed_1 mod 4 = 0  (假设)               │
│  • seed_2 = Hash(...||2), i₀^(2) = seed_2 mod 4 = 3  (假设)               │
│                                                                             │
│  每个查询位置 i₀^(j) 独立追踪整个折叠链                                    │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

### 5.6 查询位置的逐轮传递

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                    查询位置在每轮之间的计算                                  │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  【核心规则】                                                               │
│  ────────────                                                               │
│  每轮折叠后，查询位置对新向量长度的一半取模                                │
│                                                                             │
│  设第 k 轮的查询位置是 iₖ，向量长度是 mₖ = n/2^k                          │
│  则第 k+1 轮的查询位置: iₖ₊₁ = iₖ mod (mₖ/4)                              │
│                                                                             │
│  更简洁的表达: iₖ = i₀ mod (n/2^(k+1))                                    │
│                                                                             │
│  【为什么？】                                                               │
│  ──────────                                                                 │
│  折叠时，位置 i 和位置 i + m/2 合并成新的位置:                             │
│  • 如果 i < m/4，新位置就是 i                                              │
│  • 如果 i ≥ m/4，新位置就是 i - m/4 = i mod (m/4)                         │
│                                                                             │
│  【具体计算过程 (i₀ = 2, n = 8)】                                          │
│  ─────────────────────────────────                                          │
│                                                                             │

│  ╠═══════════════════════════════════════════════════════════════════════╣ │
│  ║                                                                       ║ │

│  ║                                                                       ║ │
│  ║  查询位置: i₀ = 2                                                    ║ │
│  ║  配对位置: i₀ + 4 = 6                                                ║ │
│  ║                                                                       ║ │

│  ║                ↑           ↑                                         ║ │
│  ║             位置2       位置6                                        ║ │
│  ║                └─────┬─────┘                                         ║ │

│  ║                                                                       ║ │
│  ╚═══════════════════════════════════════════════════════════════════════╝ │

│  ╔═══════════════════════════════════════════════════════════════════════╗ │

│  ╠═══════════════════════════════════════════════════════════════════════╣ │

│  ║                                                                       ║ │
│  ║  打开值: v⁽¹⁾₀ = 15,  v⁽¹⁾₂ = 10                                    ║ │

│  ║          └───┬───┘                                                   ║ │
│  ║            配对                                                       ║ │

│  ╚═══════════════════════════════════════════════════════════════════════╝ │

│  ╠═══════════════════════════════════════════════════════════════════════╣ │

│                                                                             │

│        [─] [─] [─] [─] [─] [─] [─] [─]                                     │

│             └───┼───┼────────────────┼──┐                                  │
│                 └───┼────────────────┼──┼──┐                               │
│                     └────────────────┼──┼──┼──┐                            │
│                                      │  │  │  │                            │
│         [─] [─] [─] [─] [─] [─] [─] [─]                                    │

│         │   │                                                              │

└─────────────────────────────────────────────────────────────────────────────┘
```

## 7. 安全性分析

### 7.1 如果证明者作弊会发生什么？

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                    作弊检测分析                                              │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  【作弊场景】证明者提交的向量不是任何低度多项式的求值                       │
│                                                                             │
│  例如: 随机向量 V⁽⁰⁾ = [3, 7, 2, 9, 5, 1, 8, 4]                           │
│                                                                             │
│  【问题】                                                                   │
│  ────────                                                                   │
│  证明者在收到 α₁ 后，必须提供 V⁽¹⁾                                        │
│  但 V⁽⁰⁾ 已经被 Merkle 树锁定，无法修改！                                 │
│                                                                             │
│  【证明者的困境】                                                           │
│  ────────────────                                                           │
│                                                                             │
│  选项 A: 提交"正确折叠"的 V⁽¹⁾                                            │
│  • 即严格按照折叠公式计算                                                  │
│  • 问题: 如果 V⁽⁰⁾ 不是低度多项式，V⁽¹⁾ 也不会是                         │
│  • 在后续轮次会被发现                                                      │
│                                                                             │
│  选项 B: 提交"伪造"的低度 V⁽¹⁾                                            │
│  • 让 V⁽¹⁾ 是某个低度多项式的求值                                        │
│  • 问题: V⁽¹⁾ 与"正确折叠"的结果不一致                                    │
│  • 折叠关系检查会失败                                                      │
│                                                                             │
│  【检测概率】                                                               │
│  ────────────                                                               │
│                                                                             │
│  如果 V⁽⁰⁾ 不是低度多项式:                                                 │
│  • 折叠关系在至少 (1 - ρ)/2 比例的位置不成立                              │
│  • 其中 ρ = d/n = 4/8 = 1/2                                               │
│  • 所以至少 (1 - 0.5)/2 = 25% 的位置会出错                                │
│                                                                             │
│  单次查询检测概率 ≥ 25%                                                    │
│  λ 次独立查询后，作弊逃脱概率 ≤ 0.75^λ                                    │
│                                                                             │
│  λ = 40:  逃脱概率 < 10⁻⁵                                                  │
│  λ = 128: 逃脱概率 < 10⁻¹⁶                                                 │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 7.2 安全性保证

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                       FRI 的安全性保证                                       │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  【完备性 (Completeness)】                                                  │
│  ─────────────────────────                                                  │
│  如果证明者诚实（V⁽⁰⁾ 确实是低度多项式的求值），                          │
│  验证者总是接受                                                            │
│                                                                             │
│  【可靠性 (Soundness)】                                                     │
│  ─────────────────────                                                      │
│  如果 V⁽⁰⁾ 与任何低度多项式的求值距离 ≥ δn，                              │
│  验证者以 ≥ 1 - ε 的概率拒绝                                              │
│                                                                             │
│  其中:                                                                      │
│  • δ = (1 - ρ)/2 是接近度参数                                             │
│  • ε = (1 - δ)^λ 是 soundness error                                       │
│  • λ 是查询次数                                                            │
│                                                                             │
│  【零知识性 (如果需要)】                                                   │
│  ─────────────────────                                                      │
│  标准 FRI 不是零知识的（验证者能看到部分求值）                             │
│  但可以通过添加随机掩码多项式实现零知识                                    │
│                                                                             │
│  【后量子安全】                                                             │
│  ────────────                                                               │
│  FRI 只依赖哈希函数的抗碰撞性                                              │
│  对量子计算机安全（Grover 算法仅提供平方加速）                             │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 总结

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                          FRI 协议总结                                        │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  【核心思想】                                                               │
│  ────────────                                                               │
│  通过递归折叠，将"度数 < d 的多项式验证"                                   │
│  转化为"常数多项式验证"                                                    │
│                                                                             │
│  【关键步骤】                                                               │
│  ────────────                                                               │
│  1. 证明者承诺多项式求值（Merkle 树）                                      │
│  2. 通过哈希生成随机挑战（Fiat-Shamir）                                    │
│  3. 证明者计算折叠并承诺                                                   │
│  4. 重复直到常数                                                           │
│  5. 验证者检查 Merkle 路径和折叠关系                                       │
│                                                                             │
│  【复杂度】                                                                 │
│  ──────────                                                                 │
│  • 证明大小: O(λ · log² n)                                                 │
│  • 证明时间: O(n · log n)                                                  │
│  • 验证时间: O(λ · log² n)                                                 │
│                                                                             │
│  【应用】                                                                   │
│  ────────                                                                   │
│  • STARK 证明系统的核心组件                                                │
│  • StarkNet, Plonky2, RISC Zero 等                                         │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```
