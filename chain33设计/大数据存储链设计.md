# Chain33 大数据存储链设计

## 1. 背景与动机

### 1.1 问题描述

现代零知识证明系统（如 STARKs）生成的证明数据通常较大：

| 证明类型 | 典型大小 | 说明 |
|----------|----------|------|
| SNARK (Groth16) | ~200 bytes | 最小，但需要可信设置 |
| PLONK | ~400-800 bytes | 通用可信设置 |
| **STARK** | **20-200 KB** | 无可信设置，透明性强 |
| FRI 证明 | 50-500 KB | 根据多项式度数变化 |

将大量 STARK 证明存储到主流区块链面临的问题：

```
┌─────────────────────────────────────────────────────────────────┐
│                    存储成本问题                                  │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  以太坊 Calldata 成本：                                         │
│  • 非零字节：16 gas/byte                                        │
│  • 100 KB 证明 ≈ 1,600,000 gas ≈ $50-100（高峰期更贵）         │
│                                                                 │
│  每日 1000 个证明 = $50,000-100,000/天                          │
│                                                                 │
│  这对于高频应用（游戏、DeFi、IoT）是不可接受的成本              │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 1.2 设计目标

将 Chain33 改造为专门优化大数据存储的区块链：

1. **低成本存储**：存储成本降低 100-1000 倍
2. **高吞吐量**：支持大量证明数据的快速写入
3. **数据可用性**：保证存储数据的持久性和可访问性
4. **与主链互操作**：可与以太坊等主链进行验证交互

#### 2.2.2 存储费用模型

```go
// 存储费用计算
type StoragePricing struct {
    // 基础费用（每字节）
    BasePerByte     uint64  // 基础存储费用
    
    // 时间因子
    PermanentMultiplier  float64  // 永久存储倍数（如 10x）
    YearlyRate           float64  // 年存储费率
    
    // 批量折扣
    BatchDiscount        float64  // 批量提交折扣
    
    // 数据类型折扣
    ProofDiscount        float64  // ZK 证明专项折扣
}

func CalculateFee(tx *DataStoreTx, pricing *StoragePricing) uint64 {
    size := len(tx.Data)
    baseFee := uint64(size) * pricing.BasePerByte
    
    // 应用折扣
    if tx.DataType == DataTypeSTARKProof {
        baseFee = uint64(float64(baseFee) * (1 - pricing.ProofDiscount))
    }
    
    // 时间因子
    if tx.ExpiryBlock == 0 {
        baseFee = uint64(float64(baseFee) * pricing.PermanentMultiplier)
    } else {
        blocks := tx.ExpiryBlock - currentBlock
        years := float64(blocks) / BlocksPerYear
        baseFee = uint64(float64(baseFee) * years * pricing.YearlyRate)
    }
    
    return baseFee
}
```

## 3. 交易大小限制与拆分策略

### 3.1 单笔交易大小分析

**问题**：单笔交易太大会导致以下问题：

```
┌─────────────────────────────────────────────────────────────────┐
│                  大交易的网络传播问题                            │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  1. P2P 广播延迟                                                │
│     • 大交易需要更长时间在节点间传播                           │
│     • 可能导致交易在共识轮次内无法到达所有验证者               │
│     • 增加孤块和分叉风险                                       │
│                                                                 │
│  2. 内存池压力                                                  │
│     • 大交易占用更多内存池空间                                 │
│     • 可能导致其他交易被拒绝                                   │
│     • DoS 攻击风险                                             │
│                                                                 │
│  3. 区块打包效率                                                │
│     • 单笔大交易可能无法与其他交易并行打包                     │
│     • 降低区块利用率                                           │
│                                                                 │
│  4. 验证延迟                                                    │
│     • 大交易验证时间更长                                       │
│     • 影响共识轮次时间                                         │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 3.2 交易大小限制（参考 Celestia）

**Celestia 的限制**：
- 单笔 Blob 最大：~2 MiB (1,973,786 bytes)
- 建议大小：< 500 KiB（确保快速打包）
- 区块大小：10 MB / 5 秒

**Chain33 存储链建议限制**：

| 参数 | 值 | 说明 |
|------|-----|------|
| 单笔交易推荐大小 | **256 KB** | 最佳网络传播效率 |
| 单笔交易最大大小 | **512 KB** | 确保广播可靠性 |
| 单笔交易硬上限 | **2 MB** | 极限情况，需更高 gas |
| 区块数据上限 | **10 MB** | 每区块最大数据量 |
| 区块时间 | **5 秒** | 共识轮次 |

### 3.3 大数据拆分策略

```go
// 数据拆分配置
const (
    RecommendedBlobSize = 256 * 1024  // 256 KB - 推荐大小
    MaxBlobSize         = 512 * 1024  // 512 KB - 最大大小
    HardLimitBlobSize   = 2 * 1024 * 1024 // 2 MB - 硬上限
)

// 大数据拆分结构
type SplitDataSubmission struct {
    // 原始数据标识
    OriginalDataID  [32]byte
    
    // 总分片数
    TotalChunks     uint32
    
    // 当前分片索引
    ChunkIndex      uint32
    
    // 分片数据
    ChunkData       []byte
    
    // 分片 Merkle 证明（证明属于原始数据）
    ChunkProof      []byte
    
    // 原始数据 Merkle 根
    OriginalRoot    [32]byte
}

// 自动拆分大数据
func SplitLargeData(data []byte, dataID [32]byte) ([]SplitDataSubmission, error) {
    if len(data) <= RecommendedBlobSize {
        // 无需拆分
        return nil, nil
    }
    
    // 计算分片数
    chunkSize := RecommendedBlobSize
    numChunks := (len(data) + chunkSize - 1) / chunkSize
    
    // 构建 Merkle 树
    chunks := splitIntoChunks(data, chunkSize)
    merkleTree := buildMerkleTree(chunks)
    
    submissions := make([]SplitDataSubmission, numChunks)
    for i, chunk := range chunks {
        submissions[i] = SplitDataSubmission{
            OriginalDataID: dataID,
            TotalChunks:    uint32(numChunks),
            ChunkIndex:     uint32(i),
            ChunkData:      chunk,
            ChunkProof:     merkleTree.GetProof(i),
            OriginalRoot:   merkleTree.Root(),
        }
    }
    
    return submissions, nil
}

// 重组分片数据
func ReassembleData(submissions []SplitDataSubmission) ([]byte, error) {
    // 验证所有分片属于同一原始数据
    if !validateChunks(submissions) {
        return nil, errors.New("invalid chunks")
    }
    
    // 按索引排序
    sort.Slice(submissions, func(i, j int) bool {
        return submissions[i].ChunkIndex < submissions[j].ChunkIndex
    })
    
    // 合并数据
    var result []byte
    for _, sub := range submissions {
        result = append(result, sub.ChunkData...)
    }
    
    return result, nil
}
```

#### 3.4.1 索引交易结构

```go
// 文件索引交易 - 第一个交易，包含完整的文件元数据
type FileIndexTx struct {
    // 文件唯一标识
    FileID          [32]byte    // = hash(原始文件内容)
    
    // 文件元数据
    FileName        string      // 可选：文件名
    FileType        uint8       // 0: Raw, 1: STARK Batch, 2: Rollup State, 3: Archive
    TotalSize       uint64      // 原始文件总大小
    
    // 分片信息
    TotalChunks     uint32      // 总分片数
    ChunkSize       uint32      // 每个分片大小（最后一个可能更小）
    
    // 分片哈希列表（用于验证每个分片）
    ChunkHashes     [][32]byte  // 每个分片的哈希
    
    // 文件 Merkle 根（所有分片哈希构建的树根）
    MerkleRoot      [32]byte
    
    // 压缩信息
    Compressed      bool        // 原始数据是否已压缩
    CompressionType uint8       // 0: None, 1: zstd, 2: lz4
    OriginalSize    uint64      // 压缩前大小（如果已压缩）
    
    // 过期时间
    ExpiryBlock     uint64      // 0 表示永久存储
    
    // 提交者
    Submitter       common.Address
    Signature       []byte
}

// 数据分片交易
type FileChunkTx struct {
    // 关联的文件索引
    FileID          [32]byte    // 对应 FileIndexTx.FileID
    
    // 分片位置
    ChunkIndex      uint32      // 分片索引 (0, 1, 2, ...)
    
    // 分片数据
    ChunkData       []byte      // 实际数据（≤ ChunkSize）
    
    // 验证信息（可选，用于独立验证）
    ChunkHash       [32]byte    // = hash(ChunkData)，应与 Index 中对应位置匹配
}
```

#### 3.4.2 文件提交流程

```go
// 大文件提交器
type LargeFileSubmitter struct {
    client      *Chain33Client
    chunkSize   int
}

func NewLargeFileSubmitter(client *Chain33Client) *LargeFileSubmitter {
    return &LargeFileSubmitter{
        client:    client,
        chunkSize: RecommendedBlobSize, // 256 KB
    }
}

// 提交大文件
func (s *LargeFileSubmitter) SubmitFile(data []byte, fileType uint8) (*FileSubmitResult, error) {
    // 1. 计算文件 ID
    fileID := sha256.Sum256(data)
    
    // 2. 拆分数据
    chunks := s.splitIntoChunks(data)
    numChunks := len(chunks)
    
    // 3. 计算每个分片的哈希
    chunkHashes := make([][32]byte, numChunks)
    for i, chunk := range chunks {
        chunkHashes[i] = sha256.Sum256(chunk)
    }
    
    // 4. 构建 Merkle 树
    merkleRoot := buildMerkleRoot(chunkHashes)
    
    // 5. 创建索引交易
    indexTx := &FileIndexTx{
        FileID:      fileID,
        FileType:    fileType,
        TotalSize:   uint64(len(data)),
        TotalChunks: uint32(numChunks),
        ChunkSize:   uint32(s.chunkSize),
        ChunkHashes: chunkHashes,
        MerkleRoot:  merkleRoot,
        Submitter:   s.client.Address(),
    }
    
    // 6. 提交索引交易（第一个交易）
    indexTxHash, err := s.client.SubmitFileIndex(indexTx)
    if err != nil {
        return nil, fmt.Errorf("submit index failed: %w", err)
    }
    
    // 7. 批量提交数据分片交易
    chunkTxHashes := make([]common.Hash, numChunks)
    for i, chunk := range chunks {
        chunkTx := &FileChunkTx{
            FileID:     fileID,
            ChunkIndex: uint32(i),
            ChunkData:  chunk,
            ChunkHash:  chunkHashes[i],
        }
        
        txHash, err := s.client.SubmitFileChunk(chunkTx)
        if err != nil {
            return nil, fmt.Errorf("submit chunk %d failed: %w", i, err)
        }
        chunkTxHashes[i] = txHash
    }
    
    return &FileSubmitResult{
        FileID:        fileID,
        IndexTxHash:   indexTxHash,
        ChunkTxHashes: chunkTxHashes,
        MerkleRoot:    merkleRoot,
    }, nil
}

func (s *LargeFileSubmitter) splitIntoChunks(data []byte) [][]byte {
    var chunks [][]byte
    for i := 0; i < len(data); i += s.chunkSize {
        end := i + s.chunkSize
        if end > len(data) {
            end = len(data)
        }
        chunks = append(chunks, data[i:end])
    }
    return chunks
}
```

#### 3.4.3 文件检索与重组

```go
// 文件检索器
type FileRetriever struct {
    client *Chain33Client
}

// 检索完整文件
func (r *FileRetriever) RetrieveFile(fileID [32]byte) ([]byte, error) {
    // 1. 获取文件索引
    indexTx, err := r.client.GetFileIndex(fileID)
    if err != nil {
        return nil, fmt.Errorf("get index failed: %w", err)
    }
    
    // 2. 获取所有分片
    chunks := make([][]byte, indexTx.TotalChunks)
    for i := uint32(0); i < indexTx.TotalChunks; i++ {
        chunkTx, err := r.client.GetFileChunk(fileID, i)
        if err != nil {
            return nil, fmt.Errorf("get chunk %d failed: %w", i, err)
        }
        
        // 3. 验证分片哈希
        chunkHash := sha256.Sum256(chunkTx.ChunkData)
        if chunkHash != indexTx.ChunkHashes[i] {
            return nil, fmt.Errorf("chunk %d hash mismatch", i)
        }
        
        chunks[i] = chunkTx.ChunkData
    }
    
    // 4. 重组数据
    var result []byte
    for _, chunk := range chunks {
        result = append(result, chunk...)
    }
    
    // 5. 验证完整文件哈希
    if sha256.Sum256(result) != fileID {
        return nil, errors.New("file hash mismatch")
    }
    
    return result, nil
}

// 验证文件完整性（不下载数据，只验证哈希）
func (r *FileRetriever) VerifyFileIntegrity(fileID [32]byte) (bool, error) {
    indexTx, err := r.client.GetFileIndex(fileID)
    if err != nil {
        return false, err
    }
    
    // 验证 Merkle 根
    computedRoot := buildMerkleRoot(indexTx.ChunkHashes)
    return computedRoot == indexTx.MerkleRoot, nil
}
```

#### 3.4.4 链上索引存储

```go
// 链上文件索引存储
type FileIndexStore struct {
    // FileID -> FileIndexTx
    indexes map[[32]byte]*FileIndexTx
    
    // FileID -> ChunkIndex -> BlockHeight (分片所在区块)
    chunkLocations map[[32]byte]map[uint32]uint64
}

// 查询文件索引
func (s *FileIndexStore) GetIndex(fileID [32]byte) (*FileIndexTx, error) {
    index, ok := s.indexes[fileID]
    if !ok {
        return nil, ErrFileNotFound
    }
    return index, nil
}

// 查询分片位置
func (s *FileIndexStore) GetChunkLocation(fileID [32]byte, chunkIndex uint32) (uint64, error) {
    chunks, ok := s.chunkLocations[fileID]
    if !ok {
        return 0, ErrFileNotFound
    }
    blockHeight, ok := chunks[chunkIndex]
    if !ok {
        return 0, ErrChunkNotFound
    }
    return blockHeight, nil
}

// 检查文件是否完整（所有分片都已提交）
func (s *FileIndexStore) IsFileComplete(fileID [32]byte) bool {
    index, err := s.GetIndex(fileID)
    if err != nil {
        return false
    }
    
    chunks, ok := s.chunkLocations[fileID]
    if !ok {
        return false
    }
    
    return uint32(len(chunks)) == index.TotalChunks
}
```

```go
// 大文件提交费用计算
func CalculateLargeFileFee(fileSize int, pricing *StoragePricing) uint64 {
    // 分片数
    numChunks := (fileSize + RecommendedBlobSize - 1) / RecommendedBlobSize
    
    // 索引交易费用（固定 + 分片哈希数量相关）
    indexFee := pricing.BaseFee + uint64(numChunks)*32*pricing.GasPerByte
    
    // 数据分片交易费用
    dataFee := uint64(fileSize) * pricing.GasPerByte
    
    // 总费用
    totalFee := indexFee + dataFee
    
    // 批量折扣（分片越多折扣越大，最高 30%）
    discount := math.Min(float64(numChunks)*0.01, 0.30)
    totalFee = uint64(float64(totalFee) * (1 - discount))
    
    return totalFee
}
```

### 3.5 Gas 费用与大小关系

```go
// Gas 费用随数据大小的计算（参考 Celestia）
type GasPricing struct {
    // 固定基础费用
    BaseFee         uint64  // 65,000 gas
    
    // 每字节 gas
    GasPerByte      uint64  // 1 gas/byte（基础）
    
    // 大交易惩罚系数（超过推荐大小后）
    LargeTxPenalty  float64 // 1.5x - 2x
}

func CalculateGas(dataSize int, pricing *GasPricing) uint64 {
    gas := pricing.BaseFee
    
    if dataSize <= RecommendedBlobSize {
        // 推荐大小内：线性计费
        gas += uint64(dataSize) * pricing.GasPerByte
    } else if dataSize <= MaxBlobSize {
        // 超过推荐但在最大范围内：1.5x 惩罚
        gas += uint64(RecommendedBlobSize) * pricing.GasPerByte
        excess := dataSize - RecommendedBlobSize
        gas += uint64(float64(excess) * float64(pricing.GasPerByte) * 1.5)
    } else if dataSize <= HardLimitBlobSize {
        // 超过最大但在硬上限内：2x 惩罚
        gas += uint64(RecommendedBlobSize) * pricing.GasPerByte
        gas += uint64(float64(MaxBlobSize-RecommendedBlobSize) * float64(pricing.GasPerByte) * 1.5)
        excess := dataSize - MaxBlobSize
        gas += uint64(float64(excess) * float64(pricing.GasPerByte) * 2.0)
    } else {
        return 0 // 拒绝超过硬上限的交易
    }
    
    return gas
}
```

### 4.5 纠删码实现

```go
// Reed-Solomon 纠删码配置
type ErasureCodingConfig struct {
    DataShards   int  // 原始数据分片数
    ParityShards int  // 校验分片数
    ShardSize    int  // 每个分片大小
}

// 默认配置：50% 冗余，可容忍 50% 节点离线
var DefaultConfig = ErasureCodingConfig{
    DataShards:   64,
    ParityShards: 64,
    ShardSize:    512, // bytes
}

// 编码数据
func EncodeData(data []byte, config ErasureCodingConfig) ([][]byte, error) {
    enc, _ := reedsolomon.New(config.DataShards, config.ParityShards)
    
    // 分片
    shards, _ := enc.Split(data)
    
    // 生成校验分片
    enc.Encode(shards)
    
    return shards, nil
}

// 从任意 DataShards 个分片恢复数据
func RecoverData(shards [][]byte, config ErasureCodingConfig) ([]byte, error) {
    enc, _ := reedsolomon.New(config.DataShards, config.ParityShards)
    
    // 重建缺失分片
    enc.Reconstruct(shards)
    
    // 合并数据分片
    var buf bytes.Buffer
    enc.Join(&buf, shards, len(shards[0])*config.DataShards)
    
    return buf.Bytes(), nil
}
```

#### 7.3.2 奖励分配模型

```go
// 区块奖励分配
type BlockRewardDistribution struct {
    // 总区块奖励（每区块固定产出）
    TotalBlockReward    uint64  // 如 100 Token/区块
    
    // 分配比例
    ValidatorShare      float64 // 30% - PoS 验证节点
    StorageNodeShare    float64 // 40% - 存储节点
    FullNodeBonus       float64 // 20% - 全节点额外奖励
    ProtocolTreasury    float64 // 10% - 协议金库
}

// 默认分配
var DefaultRewardDistribution = BlockRewardDistribution{
    TotalBlockReward:    100,  // 100 Token/区块
    ValidatorShare:      0.30, // 30 Token
    StorageNodeShare:    0.40, // 40 Token
    FullNodeBonus:       0.20, // 20 Token
    ProtocolTreasury:    0.10, // 10 Token
}

// 奖励计算
func CalculateRewards(block *Block, nodes *NodeRegistry) *RewardResult {
    totalReward := DefaultRewardDistribution.TotalBlockReward
    
    // 1. 验证节点奖励（PoS）
    validatorReward := uint64(float64(totalReward) * DefaultRewardDistribution.ValidatorShare)
    validatorRewards := distributeToValidators(validatorReward, block.Validators)
    
    // 2. 存储节点奖励
    storageReward := uint64(float64(totalReward) * DefaultRewardDistribution.StorageNodeShare)
    storageRewards := distributeToStorageNodes(storageReward, nodes.StorageNodes)
    
    // 3. 全节点额外奖励
    fullNodeBonus := uint64(float64(totalReward) * DefaultRewardDistribution.FullNodeBonus)
    fullNodeRewards := distributeToFullNodes(fullNodeBonus, nodes.FullStorageNodes)
    
    // 4. 协议金库
    treasuryAmount := uint64(float64(totalReward) * DefaultRewardDistribution.ProtocolTreasury)
    
    return &RewardResult{
        ValidatorRewards:   validatorRewards,
        StorageRewards:     storageRewards,
        FullNodeRewards:    fullNodeRewards,
        TreasuryAmount:     treasuryAmount,
    }
}
```

#### 7.3.3 存储证明机制 (Proof of Storage)

```go
// 存储证明 - 证明节点确实存储了数据
type StorageProof struct {
    // 节点标识
    NodeID          [32]byte
    
    // 挑战区块高度
    ChallengeBlock  uint64
    
    // 被挑战的数据 ID 列表
    ChallengedData  [][32]byte
    
    // 存储证明（Merkle 证明）
    Proofs          []MerkleProof
    
    // 时间戳
    Timestamp       uint64
    
    // 节点签名
    Signature       []byte
}

// 存储挑战 - 随机选择数据进行验证
type StorageChallenge struct {
    // 挑战 ID
    ChallengeID     [32]byte
    
    // 目标节点
    TargetNode      [32]byte
    
    // 随机种子（来自区块哈希）
    RandomSeed      [32]byte
    
    // 挑战的数据分片索引
    ChunkIndices    []uint64
    
    // 挑战发起区块
    InitBlock       uint64
    
    // 响应截止区块
    DeadlineBlock   uint64
}

// 生成存储挑战
func GenerateStorageChallenge(blockHash [32]byte, nodeID [32]byte, nodeData []DataInfo) *StorageChallenge {
    // 使用区块哈希作为随机源
    seed := sha256.Sum256(append(blockHash[:], nodeID[:]...))
    
    // 随机选择 K 个数据分片进行挑战
    K := 16 // 每次挑战 16 个分片
    indices := selectRandomIndices(seed, len(nodeData), K)
    
    return &StorageChallenge{
        ChallengeID:   sha256.Sum256(seed[:]),
        TargetNode:    nodeID,
        RandomSeed:    seed,
        ChunkIndices:  indices,
        InitBlock:     currentBlock,
        DeadlineBlock: currentBlock + 100, // 100 区块内响应
    }
}

// 验证存储证明
func VerifyStorageProof(challenge *StorageChallenge, proof *StorageProof) bool {
    // 1. 验证时效性
    if proof.Timestamp > challenge.DeadlineBlock {
        return false
    }
    
    // 2. 验证每个被挑战的数据
    for i, dataID := range challenge.ChallengedData {
        // 获取链上记录的数据 Merkle 根
        expectedRoot := getDataMerkleRoot(dataID)
        
        // 验证 Merkle 证明
        if !verifyMerkleProof(proof.Proofs[i], expectedRoot) {
            return false
        }
    }
    
    // 3. 验证签名
    return verifySignature(proof)
}
```

#### 7.3.5 全节点验证机制

```go
// 全节点存储验证
type FullNodeVerification struct {
    NodeID          [32]byte
    
    // 存储覆盖范围
    StorageRange    BlockRange  // 存储的区块范围
    
    // 随机抽查结果
    SamplingResults []SamplingResult
    
    // 验证时间
    VerifiedAt      uint64
    
    // 验证有效期（区块数）
    ValidUntil      uint64
}

type BlockRange struct {
    StartBlock  uint64
    EndBlock    uint64
}

type SamplingResult struct {
    BlockHeight uint64
    DataID      [32]byte
    Success     bool
    ResponseTime time.Duration
}

// 验证全节点存储
func VerifyFullStorageNode(nodeID [32]byte) (*FullNodeVerification, error) {
    // 1. 获取节点声明的存储范围
    node := getStorageNode(nodeID)
    
    // 2. 随机采样验证
    numSamples := 100  // 采样 100 个随机数据
    results := make([]SamplingResult, numSamples)
    
    for i := 0; i < numSamples; i++ {
        // 随机选择一个历史区块
        blockHeight := randomBlockHeight(node.StorageRange)
        
        // 随机选择该区块中的一个数据
        dataID := randomDataInBlock(blockHeight)
        
        // 请求数据
        start := time.Now()
        data, err := requestDataFromNode(nodeID, dataID)
        responseTime := time.Since(start)
        
        // 验证数据正确性
        success := err == nil && verifyData(dataID, data)
        
        results[i] = SamplingResult{
            BlockHeight:  blockHeight,
            DataID:       dataID,
            Success:      success,
            ResponseTime: responseTime,
        }
    }
    
    // 3. 计算成功率
    successCount := 0
    for _, r := range results {
        if r.Success {
            successCount++
        }
    }
    successRate := float64(successCount) / float64(numSamples)
    
    // 4. 要求 99% 以上成功率
    if successRate < 0.99 {
        return nil, fmt.Errorf("full node verification failed: success rate %.2f%%", successRate*100)
    }
    
    return &FullNodeVerification{
        NodeID:          nodeID,
        StorageRange:    node.StorageRange,
        SamplingResults: results,
        VerifiedAt:      currentBlock,
        ValidUntil:      currentBlock + 17280, // 约 1 天有效期
    }, nil
}
```

#### 7.3.6 惩罚机制 (Slashing)

```go
// 惩罚类型
type SlashingType uint8

const (
    SlashTypeStorageFailure    SlashingType = 1  // 存储证明失败
    SlashTypeUnavailable       SlashingType = 2  // 数据不可用
    SlashTypeDoubleSign        SlashingType = 3  // 双签（验证节点）
    SlashTypeFalseFullNode     SlashingType = 4  // 虚假全节点声明
)

// 惩罚比例
var SlashingRates = map[SlashingType]float64{
    SlashTypeStorageFailure:    0.01,  // 1% 质押
    SlashTypeUnavailable:       0.05,  // 5% 质押
    SlashTypeDoubleSign:        0.10,  // 10% 质押
    SlashTypeFalseFullNode:     0.50,  // 50% 质押
}

// 惩罚记录
type SlashingRecord struct {
    NodeID      [32]byte
    SlashType   SlashingType
    Amount      uint64
    Reason      string
    BlockHeight uint64
    Evidence    []byte
}

// 执行惩罚
func ExecuteSlashing(nodeID [32]byte, slashType SlashingType, evidence []byte) error {
    node := getStorageNode(nodeID)
    
    // 计算惩罚金额
    slashRate := SlashingRates[slashType]
    slashAmount := uint64(float64(node.StakeAmount) * slashRate)
    
    // 扣除质押
    if err := deductStake(nodeID, slashAmount); err != nil {
        return err
    }
    
    // 记录惩罚
    record := &SlashingRecord{
        NodeID:      nodeID,
        SlashType:   slashType,
        Amount:      slashAmount,
        Reason:      getSlashReason(slashType),
        BlockHeight: currentBlock,
        Evidence:    evidence,
    }
    
    // 惩罚金额分配：50% 销毁，50% 给举报者
    burnAmount := slashAmount / 2
    reporterReward := slashAmount - burnAmount
    
    burn(burnAmount)
    rewardReporter(evidence, reporterReward)
    
    return saveSlashingRecord(record)
}
```

```go
// 奖励发放周期
type RewardEpoch struct {
    EpochID         uint64
    StartBlock      uint64
    EndBlock        uint64
    
    // 统计数据
    TotalBlocks     uint64
    TotalDataStored uint64
    
    // 奖励池
    ValidatorPool   uint64
    StoragePool     uint64
    FullNodePool    uint64
}

// 每个 Epoch（如 17280 区块，约 1 天）发放一次奖励
const BlocksPerEpoch = 17280

// 计算 Epoch 奖励
func CalculateEpochRewards(epoch *RewardEpoch) map[[32]byte]uint64 {
    rewards := make(map[[32]byte]uint64)
    
    // 1. 获取所有活跃存储节点
    storageNodes := getActiveStorageNodes(epoch)
    fullNodes := getActiveFullNodes(epoch)
    
    // 2. 计算存储节点奖励（按存储量加权）
    totalStorageWeight := calculateTotalStorageWeight(storageNodes)
    for _, node := range storageNodes {
        weight := calculateNodeWeight(node)
        share := float64(weight) / float64(totalStorageWeight)
        reward := uint64(share * float64(epoch.StoragePool))
        rewards[node.NodeID] += reward
    }
    
    // 3. 计算全节点额外奖励（平均分配）
    if len(fullNodes) > 0 {
        fullNodeReward := epoch.FullNodePool / uint64(len(fullNodes))
        for _, node := range fullNodes {
            rewards[node.NodeID] += fullNodeReward
        }
    }
    
    return rewards
}

// 节点权重计算
func calculateNodeWeight(node *StorageNode) uint64 {
    // 基础权重 = 存储量
    weight := node.StoredDataSize
    
    // 在线时间加成（最高 1.5x）
    uptimeBonus := math.Min(float64(node.UptimeRatio), 1.5)
    weight = uint64(float64(weight) * uptimeBonus)
    
    // 响应速度加成（响应快的节点获得更多奖励）
    if node.AvgResponseTime < 100*time.Millisecond {
        weight = uint64(float64(weight) * 1.2)
    }
    
    return weight
}
```
